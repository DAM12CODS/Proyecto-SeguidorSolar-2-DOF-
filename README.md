# Proyecto-SeguidorSolar-2-DOF-

Este proyecto, desarrollado en el marco del curso de Métodos Numéricos, aborda ambos problemas de forma integrada: se emplean métodos numéricos y bibliotecas especializadas para el cálculo de la posición solar, y se desarrolla la deducción matemática completa —basada en matrices de rotación— para obtener las expresiones cerradas de pitch y roll. El resultado es un programa interactivo capaz de simular y graficar el comportamiento del seguidor para cualquier fecha y duración especificadas por el usuario.


## Como ejecutar 
Para poder ejecutar el programa es necesario que antes se tenga las dependencias que el programa hace uso, se lo podra ver en el archivo "requeriments.txt". Una vez con las dependencias listas, en una nueva terminal: 
"python Proyecto.py"
